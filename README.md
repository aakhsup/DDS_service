# DDS_service

Веб-приложение на Django для учёта личных и бизнес-финансов: пополнения и списания с привязкой к справочникам статусов, типов, категорий и подкатегорий.

## Возможности

- Создание, просмотр, редактирование и удаление транзакций (CRUD)
- Фильтрация списка по периоду дат, статусу, типу, категории и подкатегории
- Автоматический подсчёт прихода, расхода и баланса по текущему фильтру
- Зависимые выпадающие списки: категория зависит от типа, подкатегория — от категории
- Валидация на уровне формы: подкатегория должна принадлежать выбранной категории, категория — выбранному типу
- Управление справочниками (статусы, типы, категории, подкатегории) через админ-панель Django

## Стек

- Python 3.10
- Django 5.x
- SQLite (встроенная, без настройки)
- HTML/CSS (шаблоны Django, без JS-фреймворков)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/dds-project.git
cd dds-project

# 2. Создать виртуальное окружение и активировать его
python3 -m venv venv
source venv/bin/activate        # Linux/macOS
# venv\Scripts\activate         # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Применить миграции
python manage.py migrate

# 5. Создать суперпользователя (для админки)
python manage.py createsuperuser

# 6. Запустить сервер
python manage.py runserver
```

После запуска:

- Приложение: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin/

## Структура проекта

```text
dds-project/
├── dds_project/        # Настройки проекта (settings, urls)
├── dds/                # Основное приложение
│   ├── models.py       # Модели: Status, Type, Category, Subcategory, Transaction
│   ├── forms.py        # Форма транзакции с валидацией связей
│   ├── views.py        # Список с фильтрами, создание/редактирование/удаление
│   └── admin.py        # Регистрация моделей в админке
├── templates/          # HTML-шаблоны
├── static/             # CSS
└── manage.py
```

## Логика моделей

```text
Status (справочник)   ─┐
Type    (справочник)  ─┼─→ Transaction
Category ← Type       ─┤
Subcategory ← Category ┘
```

Бизнес-правила:

- Категория привязана к типу (например, «Зарплата» — только для «Пополнения»)
- Подкатегория привязана к категории
- Форма не даст сохранить несоответствующую связку

## Первые шаги после запуска

1. Зайдите в админку и заполните справочники:
   - **Статусы:** Бизнес, Личное, Налог
   - **Типы:** Пополнение, Списание
   - **Категории и подкатегории:** например, «Зарплата» → «Основная работа», «Инфраструктура» → «VPS»
2. Создайте первую транзакцию через «Добавить транзакцию»
3. Попробуйте фильтры над таблицей — баланс пересчитается автоматически
